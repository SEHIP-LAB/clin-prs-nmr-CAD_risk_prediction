## Synthetic-data tests

The automated tests use generated data and cover selected aspects of the analysis workflow, including:

- Input and output integrity checks for participant identifiers and follow-up information.
- Raw106 score derivation and five-fold candidate selection.
- Calibration, integrated Brier score, continuous NRI/IDI and decision-curve calculations.
- Survival-analysis metrics and censoring-related calculations.
- Execution of selected analysis functions in multiprocessing workers.
- Validation of required shared analysis settings.

These tests assess software structure and selected analytical functions. Study-level estimates and figures are generated by running the relevant notebooks with the authorized UK Biobank data described in `reproducibility.md`.

## Test environment

The automated software tests were run using Python 3.12.14 in a Linux environment. The corresponding test dependencies are listed in `requirements-validation.txt`.

The main analysis dependencies are listed separately in `requirements.txt`. For computational reproducibility, record the software versions and hardware configuration used for the study analyses.

## Statistical reporting

Continuous NRI and IDI are included in the relevant prediction-performance analyses. Categorical NRI requires prespecified risk categories and a documented basis for the selected thresholds; it should only be reported when those criteria are met.
